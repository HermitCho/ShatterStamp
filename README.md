# Shatter Stamp

60초 콤보 퍼즐 게임. 주어지는 모양을 보드에 찍어 블록을 부수고, **같은 색으로 연결된 블록까지 한꺼번에** 터뜨립니다.
빨리 누르는 게임이 아니라, **지금 모양으로 가장 많이 부술 수 있는 자리를 빨리 찾는** 게임입니다.

- 엔진: Godot 4.7.2 (GDScript, gl_compatibility)
- 화면: 세로 720x1280, 마우스·터치 지원
- 아트·사운드: 외부 에셋 없이 전부 코드로 생성

## 규칙

| 요소 | 내용 |
|---|---|
| 찍기 | NOW 모양을 보드에 찍으면 모양 안 블록 + 그 블록과 상하좌우로 연결된 같은 색 블록이 모두 부서지고, 위 블록이 떨어져 채워집니다. |
| 판정 | 찍은 자리의 파괴 수를 그 모양으로 가능한 **최대 파괴 수**와 비교합니다. PERFECT(100%) x2 · GREAT(75%+) x1.5 · GOOD(50%+) x1 · MISS(50% 미만) x0.5 |
| MISS | 콤보가 끊기고 시간 -1초 |
| 점수 | (n² + 10n) x 판정 배율 x 콤보 배율 — 크게 한 번 부수는 쪽이 작게 여러 번보다 이득 |
| 콤보 | GOOD 이상으로 2.4초 안에 다시 찍으면 이어짐. 3 / 6 / 10콤보에서 배율 x1.5 / x2 / x3(피버) |
| 시간 보너스 | 한 번에 얻은 점수가 **목표 점수**(900 + 75 x 경과 초) 이상이면 +1초, 2배 이상이면 +2초. 목표는 계속 오릅니다. |
| 연타 방지 | 찍은 뒤 0.35초 동안 다음 찍기 불가 |
| HOLD | 지금 모양을 보관/교체 (한 번 찍을 때마다 1회) |

조작: 클릭/탭 = 찍기 · 우클릭/Space/HOLD 칸 탭 = 보관 · ESC/P/`II` = 일시정지

## 밸런스 검증

규칙은 화면과 분리된 순수 로직(`scripts/game_rules.gd`, `scripts/board_model.gd`)이라 봇으로 대량 시뮬레이션할 수 있습니다.

```
Godot --headless --path . --script res://tests/sim_balance.gd -- --runs=30
```

30판 평균 결과:

| 봇 | 플레이 방식 | 평균 점수 | 게임 길이 |
|---|---|---|---|
| spam | 아무 데나 최대한 빨리 | 13,585 | 23.6초 |
| sloppy | 상위 절반 자리, 빠르게 | 36,582 | 44.0초 |
| decent | 최대의 75% 이상 자리, 약 1초 | 81,453 | 64.6초 |
| careful | 항상 최고 자리, 약 2초 | 58,752 | 64.4초 |
| expert | 항상 최고 자리, 빠르게 | 159,397 | 73.6초 |

막 누르면 MISS가 절반을 넘어 시간이 빨리 줄고, 정확하고 빠를수록 점수와 남은 시간이 늘어납니다.

## 구조

```
scripts/
  board_model.gd   보드 순수 로직: 연결 블록 탐색(BFS), 낙하, 보충
  game_rules.gd    판정, 점수, 콤보, 시간 규칙
  bot.gd           최대 파괴 자리 계산 (판정 기준 + 자동 플레이 + 시뮬레이션)
  shapes.gd        모양 정의 (회전 없음, 방향별 변형)
  shape_queue.gd   주머니 섞기 방식 모양 큐
  board.gd         보드 화면, 입력, 블록 애니메이션
  main.gd          게임 흐름, HUD, 타격감 연출
  menus.gd         타이틀 / 설명 / 설정 / 일시정지 / 결과 화면
  fx.gd, sfx.gd    파편·충격파 이펙트, 코드 합성 효과음
tests/
  test_board_model.gd   단위 테스트
  sim_balance.gd        봇 밸런스 시뮬레이션
```

테스트 실행: `Godot --headless --path . --script res://tests/test_board_model.gd`

디버그 실행 인자: `-- --autoplay` (봇 자동 플레이), `-- --shots=<폴더>` (주기적 스크린샷), `-- --menu=<title|howto|settings|pause>`
